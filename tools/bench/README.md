# Synthetic bench test kit

Bench equipment — **not a Scottina feature.** A deterministic CAN emitter plus
the expected decode of every frame it sends, so Light's gauge and Prime's
decoder are verified **numerically**, against ground truth, rather than by eye.

- Table: [`tests/fixtures/tables/synthetic-marine.json`](../../tests/fixtures/tables/synthetic-marine.json)
  (generated by [`generate.py`](../../tests/fixtures/tables/generate.py))
- Emitter: [`syn-emitter.py`](syn-emitter.py)
- Golden vectors: [`tests/fixtures/golden/syn-marine.jsonl`](../../tests/fixtures/golden/syn-marine.jsonl)
- Tests: [`tests/test_syn_emitter.py`](../../tests/test_syn_emitter.py),
  [`tests/test_fixtures_synthetic.py`](../../tests/test_fixtures_synthetic.py)

## Safety envelope

- Every PGN is in **reserved data page 3** (`pgn >> 16 == 3`); no real
  NMEA2000/J1939 device transmits or acts on this range. The emitter
  **asserts** this on every id it builds — a comment is not enforcement.
- **Manufacturer ID is 2046 (0x7FE)** — unassigned, so it cannot be mistaken
  for any vendor. (2047/0x7FF would be the all-ones NA sentinel and decode as
  not-available; 2046 is a real value, deliberately just below it.)
- **No actuation semantics** anywhere — no gear/throttle/trim/helm/steering in
  any field name, unit, or enum label. `SYN-` neutral names throughout.
- Emitter **refuses to transmit** without `--bench-bus-confirmed` and prints
  the PGN list + bitrate first. `--dry-run` generates ground truth off-bus.
- Emitter lives under `tools/bench/` (not a package); no Scottina package
  constructs these frames — asserted by
  `test_syn_emitter.py::test_no_scottina_package_constructs_these_frames`.

## §2 schema gaps found (report — not papered over)

Verified by decoding synthetic-marine with `kilodash/n2k.py`:

1. **Conditional field — was a live correctness bug, now FAIL-SAFED.**
   `SYN Feedback A` field 11 (`SYN Scaled Value`) means `0.1 SYN-pct` when
   `SYN Select` bit 1 is clear and `0.25 SYN-rpm` when set. §2 carries exactly
   one `(Resolution, Units)` per field, so it **cannot express** the condition —
   and a naïve decode produced a **2.5×-wrong value with the wrong unit**,
   silently and plausibly, for any real table using this common pattern. Fixed:
   the field is marked `Undecodable` (§2) and n2k renders it `n/d` (not a
   number) with a reason; the emitter's ground truth is `None` and
   `test_syn_emitter.py` asserts the fail-safe. The `cond` block still
   documents both intended meanings for reference. The actual §2 extension is
   **proposed** in `TABLES.md` §8 (recommendation: match Canboat
   `LOOKUP_FIELDTYPE`).

2. **Per-bit flag semantics — GAP.** §2 has `Lookup` (one-of-N over the whole
   field value) but no notion of named bits. A 4-bit `SYN Mode Flags` field
   decodes as an opaque number 0–15, not `{bit0: …, bit1: …}`. The only
   faithful encoding of named flags today is **one 1-bit field per flag** (as
   `SYN Flags` does with eight 1-bit fields). Canboat expresses this natively
   with `BITLOOKUP` / `LookupBitEnumeration` (TABLES.md §8) — match it if we
   build a flag renderer.

3. **Not-available sentinel — PRESENT; a fixed convention, not a bug.** §2/n2k
   reserve the all-ones raw (unsigned) / max-positive (signed) of any field
   **≥2 bits** as not-available. Consequences (all correct behaviour, now
   documented by tests rather than filed as gaps):
   - a **lookup label cannot claim a field's all-ones value** — it is shadowed
     by NA and never renders (`test_lookup_cannot_claim_all_ones`). This is why
     `SYN Category` has no `0xF` label and why `SYN Manufacturer ID` uses
     **2046** (`0x7FE`, a real value), not 2047 (`0x7FF`, the sentinel);
   - a wide flag field's all-bits-set (`0xF` for 4 bits) decodes NA, so
     "all flags set" is unrepresentable in a multi-bit flag field (use 1-bit
     fields — see gap 2);
   - signed 8-bit NA = `0x7F` (127), matching the spec.
   The constraint to remember: you cannot store the max value of a ≥2-bit
   field as real data.

4. **Signedness — PRESENT.** §2 carries `Signed`; two's-complement over
   `BitLength`; signed NA = max-positive. Confirmed (raw 156 → −100, `0x7F` →
   NA). No gap.

## Running the emitter

```sh
# ground truth only, no bus (how the golden vectors are made):
python tools/bench/syn-emitter.py --dry-run --duration 0.6 --sources 2 \
    --seed 1 --out tests/fixtures/golden/syn-marine.jsonl

# transmit on a confirmed bench bus (can0 already up at 250k):
python tools/bench/syn-emitter.py --interface can0 --bench-bus-confirmed \
    --duration 10 --sources 2
```

`--seed N` reproduces an identical frame sequence (values + schedule). The TX
path is verified: on a `vcan0` loopback, all transmitted frames' `(id, bytes)`
matched the ground truth exactly (see the commit that added this kit).

## Golden vectors

`syn-marine.jsonl` is one deterministic dry-run (`seed 1, duration 0.6,
sources 2`, 178 frames), edge-covering: every Category enum incl. the shadowed
NA, both Select states, signed −100/0/+100/NA, flag all-clear/all-set. Prime's
`n2k.py` decodes each frame and must match the ground-truth field values
exactly — the first end-to-end numeric check the decoder has had. The same
file is Light's decode fixture: both consumers verified against one truth.

Regenerate with the `--dry-run` command above; the test fails if it drifts.

## Phase 6 — budget arithmetic

The picker's rate budget is `Σ over selected (pgn, source) of 1000/interval_ms`:

- `SYN Rapid A`/`SYN Rapid B` at `interval_ms 20` = **50 fps each per source**.
- Selecting **both Rapids across 2 sources** = 4 streams × 50 = **200 fps**.
- Against Light's thresholds (**warn 100, refuse 200**) that selection hits the
  **refuse-to-arm** threshold exactly — the intended stress case.
- `SYN Unknown` has no `interval_ms`; any selection including it makes the
  budget a **lower bound** (the unknown term contributes 0 to the floor).

Light's budget code is not in this repo (it is Light-side). The emitter
produces exactly this **measurable** 200 fps, so the thresholds can be checked
against real traffic rather than guessed. **If warn 100 / refuse 200 prove
wrong against measured traffic, that gets reported — not silently retuned.**
